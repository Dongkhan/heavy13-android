# 무거운 13 (Heavy 13)

데블스 플랜 시즌3 감옥 매치 **무거운 13**을 한 기기에서 플레이하는 비공식 팬 구현입니다. 넷플릭스·제작사와 무관하고, 판매·광고 없습니다.

## 플레이

- 1인: 나 vs 컴퓨터 6명
- 2인: P1·P2가 같은 판에서 컴퓨터 5명과 함께, 한 기기를 번갈아 사용
- 온라인 대전 없음

Android 6(API 24) 이상. 알 수 없는 앱 설치를 허용한 뒤 `heavy13-0.3.apk`를 설치합니다. 이미 0.1·0.2가 있으면 지우지 않고 덮어쓰면 됩니다.

브라우저로 보려면 `play/index.html`을 열면 됩니다.

## 규칙 요약

- 7명, 14라운드. 각자 바위 카드 0~6, 빨강·초록·파랑 칩 2개, 레인보우 1개
- 매 라운드 카드 1장 + 칩 1개 동시 비공개 제출. 컴퓨터도 이번 라운드 남의 칩을 보지 않음
- 배치 순서: 레인보우 → 숫자 큰 순 → 동점은 선 플레이어부터 시계 방향
- 배치 때 1회 패스 가능. 여러 명이면 패스한 역순으로 맨 뒤에 배치
- 받침대 합이 13 이상이면, 올리기 전에 있던 바위 **개수**만큼 벌점. 방금 올린 바위는 남음
- 7라운드 뒤 패만 다시 받고 받침대는 유지
- 벌점 적은 사람이 상위. 동점이면 더 최근에 벌점을 받은 쪽이 아래. 같은 라운드면 더 늦게 터진 쪽이 아래
- 1라운드 선은 시드로 정하고, 이후 선은 그 라운드 마지막 벌점

## 빌드

Windows에서 로컬 Android SDK로 서명된 debug APK를 만듭니다.

```
python D:/DK/edu/heavy13/tools/build_apk.py
```

규칙 테스트:

```
node D:/DK/edu/heavy13/tests/test_engine.js
```
